## ✨ 핵심 특징 (Key Highlights)

### 1. 🌸 사쿠라 오로라 네오 글래스모피즘 UI (`Midnight Sakura` & `Crystal Sakura Day`)
- **듀얼 글래스 테마**: 심연의 인디고 밤하늘 위로 사쿠라 핑크·시안·교토 바이올렛 오로라와 유리 꽃잎 파티클이 유영하는 **`Midnight Sakura`** 다크 모드와, 맑고 산뜻한 주간 학습용 **`Crystal Sakura Day`** 라이트 모드를 즉시 전환할 수 있습니다.
- **정밀 `<ruby><rt>` 후리가나 조판 & WCAG AAA 가독성**: 한자 위 후리가나(`<ruby><rt>`)가 겹치거나 넘치지 않도록 정밀 설계되었으며, 반투명 유리(`backdrop-filter`) 위에서도 두 테마 모두 **WCAG AAA(7.0:1 이상)** 텍스트 명도 대비와 모바일(`360×640`) 무결점 반응형 레이아웃을 보장합니다.
- **100% 오프라인 · 무의존성 사운드 엔진**: 외부 폰트나 오디오 CDN 없이도 **Web Audio 일본풍 5음계 크리스탈 신디사이저(`sfx`)**와 **`ja-JP` 원어민 발음 TTS(`1.0x` 일반 / `0.78x` 또박또박 청해 속도 전환)**가 로컬 `file://`과 웹 양쪽에서 즉시 작동합니다.

### 2. 🧠 한국인 JLPT N5 수험생 맞춤 2-Phase 기억 루프
1. **Phase 1 — 10단어 사쿠라 프리즘 기억 공방 (`MEMORIZE`, 30/45/60초 + 15초 연장)**
   - **3D 유리 플립 카드**: 앞면(한자·후리가나·한글 발음 가이드·품사·뜻·이모지) ↔ 뒷면(한국 한자음 대조 & 장음/촉음 암기 팁·빈칸 예문·해석) 입체 학습.
   - **4단 능동 인출(Active Recall) 성에 가리기**: `[전체 보기 | 후리가나만 가리기 | 뜻 가리기 | 일본어 가리기]` 4단 토글 지원! 특히 **후리가나 가리기** 모드에서는 오쿠리가나는 남기고 한자 위 `<rt>` 읽기만 성에 블러 처리하며, 마우스 호버/터치 시 즉시 걷혀 실전 한자 독해력을 극대화합니다.
   - **⭐ 핀 바운티(Pin Bounty) & ⚡ 조기 출격 부스트**: 헷갈리는 단어 최대 3개에 별표 배팅 시 정답 점수 **×2.0 폭발**, 암기를 일찍 마치고 출격하면 남은 시간에 비례해 **즉시 보너스 점수 + 최대 ×1.30 점수 배율 + 초기 피버 게이지**를 획득합니다.
2. **Phase 2 — JLPT N5 실전 직결 3-Wave 입체 인출 배틀 (`BATTLE`)**
   - **Wave 1 · 스피드 N5 실전 퀴즈 (재인)**:
     - 🈶 **한자 읽기(`kanji-to-kana`)**: 후리가나 없는 한자(`先生`, `学校`, `来週`)를 보고 **장음(`えい/おう`)·촉음(`っ`)·탁음(`゛`)·요음 함정 보기** 중 정확한 히라가나 선택 (순수 가나 단어는 자동으로 뜻/예문 문제로 분기)
     - 🇯🇵→🇰🇷 **일→한**, 🇰🇷→🇯🇵 **한→일**, 📝 **일본어 문맥 빈칸(`［　　］`)**, 🔊 **`ja-JP` 청해 리스닝** 혼합 출제!
   - **Wave 2 · 사쿠라 글래스 매트릭스 매칭 (연합)**: 일본어 표기 5장 ↔ 한국어 뜻(또는 한자↔히라가나) 5장 스피드 터치 매칭으로 콤보 및 **SAKURA FEVER(12초간 점수 ×2.0 & 타이머 감속)** 급속 충전!
   - **Wave 3 · 가나 크리스탈 샤드 & 영문 로마자 라이브 브릿지 + 🔥 보스 리벤지 (산출)**:
     - 모라(박자) 단위로 분할된 히라가나/가타카나 유리 샤드 조각(함정 가나 포함)을 터치해 단어를 완성합니다.
     - **⌨️ 일본어 자판(IME) 불필요! 영문 로마자 실시간 타격**: 일반 영문 키보드로 `sensei`, `gakkou`, `chotto`, `shinbun`, `koohii`(`ko-hi-`)를 타이핑하면 헵번식·훈령식·촉음·발음(`n/nn`)을 자동 인식해 대응하는 가나 샤드가 실시간으로 조립됩니다!

### 3. 📖 오십음도 치트시트 · 라이트너 4단계 숙련도 · 500단어 프리즘 도감
- **あ/ア 오십음도 글래스 모달**: 입문자를 위한 **청음 · 탁음/반탁음 · 요음 · 촉음/장음/발음 규칙** 치트시트 내장 — 각 글자를 클릭하면 즉시 `ja-JP` 발음을 들려줍니다.
- **라이트너 숙련도(Box 0~3) & 3대 모드**:
  - 🗺️ **50라운드 캠페인 월드맵**: `Lv.1 N5 입문 기초(R1~20, 200단어)` → `Lv.2 N5 핵심 활용(R21~38, 180단어)` → `Lv.3 N5 실전 완성(R39~50, 120단어)` 단계별 정복 및 `S+ ~ C` 랭크 결산.
  - 🔥 **오답 · ⭐별표 리벤지 도장**: 틀렸거나 별표로 찜한 취약 단어만 골라 집중 복수전.
  - ⚡ **무한 서바이벌 블리츠**: 전 500단어 풀에서 하트 3개로 최고 기록 도전.
  - 📚 **500단어 N5 프리즘 도감**: **한자 · 히라가나/가타카나 · 영문 로마자 · 한글 발음 · 한국어 뜻** 통합 검색 및 8대 품사(`명사`, `1류동사`, `2류동사`, `3류동사`, `い형용사`, `な형용사`, `부사`, `표현`) 필터링 지원.

## 🚀 실행 방법 (빌드 불필요 · Zero-Dependency)

패키지 설치나 번들러 없이 브라우저만으로 즉시 실행됩니다.

1. **가장 빠른 로컬 실행**: 프로젝트 루트의 [`index.html`](./index.html) 파일을 더블클릭하여 브라우저(`Chrome`, `Edge`, `Safari` 등)로 바로 열기 (`file://` 완벽 호환)
2. **로컬 정적 서버 실행 (선택)**:
   ```bash
   npx serve .
   # 또는 Python 사용 시
   python -m http.server 8080
   ```
